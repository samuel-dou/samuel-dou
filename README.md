Robot Control (Overall System):
This class controlled our entire robot, frequently using methods from the Shooter and Turret systems that I developed with the Software team. I worked in this class, particularly in the loop section, to optimize loop times by reducing redundant hardware interactions and debugging the shooter’s inaccuracies.
https://github.com/Skyhawkbotics/DECODE/blob/master/TeamCode/src/main/java/org/firstinspires/ftc/teamcode/core/Robot.java

Arduino Arcade Game Project repository:
I created an Arduino-based LED Arcade game, testing a user's reaction speed. The repository contains my code, a description of the game, and a circuit diagram.
https://github.com/samuel-dou/arduino_led_arcade_game
